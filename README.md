# Приводка — шаблон сайта маркетингового агентства (7 страниц)


## Структура

```
  index.html              главная
  services.html           услуги
  portfolio.html          портфолио: фильтр, кейсы во всплывающем окне, слайдер «было / стало»
  about.html              о компании: история, принципы, команда, контакты (#contacts), реквизиты
  privacy.html            политика конфиденциальности (152-ФЗ)
  consent.html            согласие на обработку персональных данных (отдельный документ)
  cookies.html            политика cookie
  style.css               подключает все стили из assets/css
  assets/css/             base, layout, components, home (главная), pages (внутренние)
  assets/js/main.js       вступление, переходы между страницами, меню, анимации, формы, cookie
                          (вступление показывается один раз за визит; цвета — в начале assets/css/base.css)
  assets/fonts/           Unbounded и Golos Text (лицензия OFL, файлы рядом)
  assets/images/          favicon. Места под фото отмечены заглушками (блок .ph):
                          замените <div class="ph">…</div> на <img src="assets/images/...">
```

## Что заменить перед запуском

- название, телефон, почту, адрес, ИНН/ОГРН в шапке, подвале и форме
- кейсы в блоке «Оттиски» — сейчас демонстрационные
- отправку форм: assets/js/main.js, поиск «Подключите отправку»
- Яндекс Метрику: main.js, функция loadAnalytics (запускается только после согласия на cookie)

## Документы

Документы — шаблон: впишите реальные данные оператора (название, ИНН, ОГРН, адрес,
почту) и перед запуском покажите их юристу. Если подключаете CRM или другие сервисы,
допишите их в раздел о передаче третьим лицам.
